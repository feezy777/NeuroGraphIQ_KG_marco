# Gate 6D — Function vs NeurobiologicalProcess

Ontology IRI: `https://neurographiq.org/ontology/human-brain`

---

## 1. 保持区分

- `Function ≠ NeurobiologicalProcess`。
- 本轮**不新增** Function → NeurobiologicalProcess 关系。

## 2. 为什么

- encoding / retrieval / plasticity / pruning 看似"功能步骤"，但可能属 NeurobiologicalProcess / cognitive operation / task component / computational process。
- 是否建模为 Function 需后续单独科学审查。

## 3. 本轮结论

- Function part_of：DATABASE SEMANTIC RESERVED / DEFERRED。
- 不新增 Function–Process semantic relation。
- 未来需单独设计 Function–Process semantic relation。
